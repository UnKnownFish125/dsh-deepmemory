# deepmemory 设计语义层 codex 审核（二轮——模型缺陷+场景缺口）

> 模型：codex-auto-review（uuapi）/123K tokens/静态审阅+5 项内存行为复核
> 关注：记忆概念/数据模型缺陷 + 未考虑使用场景（设计层——非代码 bug）

## ① 模型缺陷（P0/P1）
### P0（立改）
1. **无"当前可信事实"语义**——disputed/decision_status/lifecycle_expires_at 不参与主检索；事件时间≠有效时间——旧决定继续指导行动 → 建立有效/记录时间+冲突组+替代链；区分"当前采信/历史回顾/争议调查"查询
2. **语义相似=事实相同**——相似即覆盖/聚合归档——"允许/禁止""生产/测试"高度相似→修正与反证被当重复 → 按主体/属性/条件/有效期识别断言；相似度只发现候选（重复/补充/矛盾三判）
3. **规则固化把出现次数当确认次数**——两条相似 preference=候选；重复抽取冒充确认 → 独立确认事件+授权晋升+适用条件/版本/撤销关系

### P1（精选）
- 无**断言级证据链**（哪句原文支持哪个版本事实——来源 ID/哈希/片段定位/支持-反驳-派生关系）
- **重要性/热度/有效性混一信号**（搜索刷新访问时间；0.85 免衰减→错误热点存活、低频关键规则消失）
- **遗忘循环**（<0.4 退出召回难强化；30 天按未访问→31 天未访问直接 archive；status=archived ⊥ storage_tier=archive）
- 检索无"无相关记忆"判定（RRF 相对名次——0.001/0.999 同分 0.875——非概率）
- 多文本字段无事实主本（content/key_facts/persona_summary/atoms 独立变化）
- **scope 三义混合**（来源/适用范围/共享范围——换会话就忘 vs 局部被泛化）
- 分类层次混乱（episode 聚合/plan 意图/decision 流程/rule 规范 + memory_class 混期限/存储）
- 实体名=身份（同名混同/别名分裂；关系单源）

## ② 场景缺口
### P0
- **记忆毒化**（授权代理恶意内容→偏好/规则；摘要/固化传播污染）→ 来源信任等级继承+不可信进候选区+晋升需确认+撤销联动
- **隐私/数据权利**（删除未覆盖派生/备份；无"不记忆"/最小化）→ 主体导出/派生删除/备份到期/恢复重放删除

### P1
- 迁移灾备（备份遗漏 InfoStore/规则/嵌入元数据；迁移重置时间→旧决定复活）
- **真实效用评估**（命中≠价值——无同题有/无记忆对照、错误诱导率、过时采用率）
- 多用户/团队（per-user 偏好 vs 团队共识/组织规则；所有权/共享权限未建模）
- 10 万级/多工作区（全库 3k 候选；固化平方级比较；小工作区候选占满）
- 离线/低资源（嵌入故障无关键词降级；供应商整体故障无解）

### P2
- 多模态（文档/图片/代码来源：缺附件身份/页码/区域/行号/commit；OCR 损失）
